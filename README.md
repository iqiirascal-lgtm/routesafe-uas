# RouteSafe - Aplikasi Optimasi Rute Evakuasi Bencana

## Deskripsi Proyek
RouteSafe adalah aplikasi berbasis web yang dirancang untuk membantu masyarakat menemukan rute evakuasi tercepat dan teraman saat terjadi bencana (seperti banjir) menggunakan Algoritma A* (A-Star) dengan pembobotan dinamis.

Proyek ini dikembangkan sebagai Tugas Akhir (UAS) Mata Kuliah **Software Engineering**.

## Struktur Repository
- `/docs` : Berisi dokumen pendukung (SRS, ERD, Diagram BPMN, Laporan SQA, Notulen).
- `/src` : Berisi source code aplikasi (PHP, HTML, CSS, JS).
- `/tests` : Berisi skenario pengujian (Test Case, Test Plan, Bug Report).

## Tech Stack
- **Backend:** PHP (Native OOP / Laravel)
- **Frontend:** HTML5, Bootstrap 5, Vanilla JavaScript
- **Database:** MySQL
- **Mapping:** Leaflet.js + OpenStreetMap
- **Version Control:** Git & GitHub

## Cara Menjalankan Proyek (Local)
1. Clone repository ini: `git clone https://github.com/username-kamu/routesafe-uas.git`
2. Import file database (akan disediakan di folder `/docs`) ke phpMyAdmin.
3. Jalankan server lokal (XAMPP).
4. Akses aplikasi melalui browser.
